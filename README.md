# Christmas

**Christmas Tree Night** is a small animated Christmas scene drawn in soft dot and diamond pixels: a flowing swirl builds the tree, multicolor lights wrap it, and a star flares on top.

## How to open it

Download or clone this repo and open `index.html` in any web browser. It is a single self-contained file, so there is nothing to install.

## Controls

- **R** replays the animation
- **D** switches between circle and diamond pixels
